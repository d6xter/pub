Publiczne pliki do pobrania.

## Kółko i krzyżyk (Android)

- Pobierz najnowszą wersję: [kolko-i-krzyzyk.apk](kolko-i-krzyzyk/kolko-i-krzyzyk.apk) (Android 8 lub nowszy)
- [`kolko-i-krzyzyk/version.json`](kolko-i-krzyzyk/version.json) mówi zainstalowanej aplikacji, jaka wersja jest najnowsza. Na tej podstawie gra przy uruchomieniu proponuje aktualizację.

Kod źródłowy gry jest w osobnym, prywatnym repozytorium.
